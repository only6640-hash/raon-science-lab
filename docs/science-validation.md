# RAON 전기·전자 탐구실 검증 기록

기준: 2026-11-06. 전기·전자 목록의 83개 주제에 명시적 ID와 전용 모형 설정을 부여했습니다. 기존의 52개 스튜디오를 주제와 무관하게 연결하던 방식은 카테고리에서 제거했습니다.

## 구현과 범위

- `electricity/index.html`, `lab.css`, `lab.js`: 검색·분야 선택, SVG 관찰 화면, 그림 바로 아래 조작부, 실시간 수치, 예측→관찰→설명, 결과 기록·CSV·인쇄, 재생/정지·초기화.
- `labs/modules/circuits.js`: 회로 주제의 기본 모형. 직·병렬과 혼합 연결, 옴의 법칙, 같은 연결망, 독립 병렬 부하, 전구 열 모형, 송전, 브리지, 계단 스위치.
- `labs/modules/electrostatic.js`: 19개 정전기·재료·전위 측정 주제. 자유 전자와 고정 이온, 유전체, 접촉·분극, 검전기, 전위와 전기력선, 전하 보존, 에너지 띠.
- `labs/modules/magnetic.js`: 23개 자기·전자기 주제. 자석·코일·직선 도선, 유도·로렌츠 힘, 전동기·발전기·변압기, 전류계 구조, 자화·분리.
- `labs/modules/electronics.js`: 전자회로·파동 주제의 기본 모형. RC/RL/LC/RLC, 논리 회로, 다이오드·트랜지스터·LED, 필터·정류, 센서와 통신, 음극선관·전자기파.
- `labs/modules/circuit-editor.js`: 10·37·43번의 자유 배선/건물 배선 공방. 이전 고정 구성 모형을 대체하며, 최종 등록 모형은 총 83개입니다.
- `labs/electricity-studio.html?topic=N`의 기존 주제 링크는 새 탐구실의 같은 주제로 이동합니다. 기존 별도 회로 페이지와 메인 사이트의 다른 콘텐츠는 유지합니다.

각 항목은 해당 주제의 관찰 대상, 조작 변수, 결과와 가정을 제공합니다. 관련 주제는 물리 엔진을 공유할 수 있으며, **83개의 원본 프로그램을 복제하거나 동일 기능을 재현했다는 의미가 아닙니다.** 그림과 코드는 독립 제작했습니다. 원본 주제 출처는 각 실험의 교사용 안내에 링크했습니다.

## 수행한 코드·수치 검증

저장소 루트에서 `node tests/run.cjs`로 재현할 수 있습니다. 외부 패키지 없이 Node.js로 실행됩니다.

- 83개 ID의 누락 여부, 모형 계약, 기본값·최솟값·유효한 중간값·최댓값·동시 극값, 여러 표시 시각을 검사했습니다.
- 각 조작부가 적용되는 모드에서 SVG 또는 측정값을 실제로 바꾸는지 검사합니다. 예: 금속의 띠틈은 0이며 반도체를 선택했을 때에만 띠틈 조작이 적용됩니다.
- NaN/Infinity/undefined 출력, 음수 SVG 크기, JavaScript 문법을 검사했습니다.
- 직렬 KVL, 병렬 KCL, 스위치 OFF, 휘트스톤 평형, 계단 스위치 네 상태.
- 전하 보존, 검전기 외부 전하의 부호, 쿨롱/전위 역법칙, 축전기 저장 에너지, 유전체 조건, 물 분자의 대칭과 쌍극자.
- 직선 도선 5 A·8 cm에서 12.5 μT, 전류 반전, 0 전류, 중성 입자, 유도 기전력 부호, 전동기/발전기/변압기 관계.
- RC/RL의 시간 상수에서 63.2%, LC 에너지 보존과 0 기준선, 반파·전파 정류의 평균/RMS, AC 0 Hz, 트랜지스터 전류 보존, 가시광선 선택 가능 여부.
- 편집기 개방·단락·부동 회로, 전압계 극성, 역방향 중복 가지, KCL 및 소비 전력 보존을 검사했습니다. 별도 독립 검토에서 600개 결정적 무작위 연결망을 검사했습니다.
- 마이크는 명시적 버튼을 누른 뒤 브라우저 허용이 있어야 동작하며, 미허용·정지·탐구 이동·늦게 도착한 허용 결과에 대한 정리 로직을 모의 검사했습니다. 실제 기기 권한창은 검사하지 못했습니다.
- 목록 탐색·83개 주제의 조건 변경/초기화·기록/검색/메뉴 상태를 DOM 계약 모형에서 검사했습니다.
- 모든 기본 SVG를 이미지로 렌더링하고 접촉 시트로 확인했습니다. 일부 극값 이미지도 별도로 확인했습니다.

**실제 브라우저 확인:** 클라우드 Chrome에서 83개 메뉴를 모두 눌러 제목·SVG 장면·조작부·결과가 로드되는 것을 확인했습니다. 데스크톱 화면을 직접 확인하고 직렬→병렬 변경, 스위치 열기(전류 0), 초기화, 조건·결과 기록, 자유 배선 공방의 스위치·병렬 시작·부품 추가를 조작했습니다.

**검증 한계:** 실제 휴대폰·태블릿 터치, 모바일 화면, 다운로드·인쇄 대화상자, 전체 화면 동작, 실제 마이크 권한·입력은 확인하지 못했습니다. 83개 경로 로드 검사는 각 조작의 실제 기기 종합 검사를 대신하지 않습니다.

참고 사이트의 83개 주제 중 82개 설명 페이지를 읽어 학습 주제를 대조했습니다. 28번 빈 깡통 페이지는 도구에서 열리지 않아 원본 기능 대조를 확인하지 못했으며, 중성 도체의 분극과 인력을 독립적으로 구현했습니다. 설명 페이지 대조는 원본 인터랙티브 화면을 직접 조작한 검증과 다릅니다.

## 모형의 중요한 경계

1. 자유 배선 공방은 단자 8개와 부품 16개까지 연결할 수 있습니다. 단자 선택으로 배선을 바꾸고 단자를 옮길 수 있습니다. 한 개의 이상 전원, 선형 부품, 정상 상태를 해석하며 SPICE 전체 기능이나 비선형 소자·과도 해석을 제공하지 않습니다.
2. AC 공방은 복소수 노드 해석을 사용합니다. 저항·코일·축전기·정격 V/P로부터 얻은 저항성 가전 부하를 배선할 수 있습니다. 실제 전원·부품 정격 계산에 사용하지 않습니다.
3. micro:bit 항목은 가상 ADC 측정이며 하드웨어와 연결되지 않습니다.
4. 전하 분포, 자기 구역, 오로라, 분류·유도, 반도체 공정, 터치스크린과 통신은 단순화한 설명 모형입니다. 수치 계산과 정성적 도식의 범위를 각 화면에 명시했습니다.
5. 빠른 입자·파동·자유진동의 애니메이션은 관찰을 위해 축척 또는 속도를 조절합니다. 실제 시간·길이·진동수와 표시의 차이는 각 모형 설명을 확인하세요.
6. 실제 회로에서는 온도, 내부저항, 기생 성분, 비선형성, 포화, 정격, 누설, 측정기 부하가 중요합니다. 반영한 것과 생략한 것을 각 화면에 표시했습니다.
7. 실제 수업 실습은 교사 지도와 저전압·전류제한 전원을 사용합니다. 가정용 전원 배선, 단락, 고전압 실험을 따라 하지 않습니다.
