# 전기·전자 수업 검증 범위

## 이번 수정의 기준

83개 주제를 각각 대조하고, 원본의 교육적 위치 관계와 조작-관찰 관계를 우선했습니다. 예를 들어 첫 회로의 전압은 세워진 전지와 도선 높이로, 같은 회로는 연결을 유지한 연속 변형으로, 축전기는 전지·극판·전구의 실제 연결 관계로 설명합니다. 그림과 코드는 독립 제작했습니다.

최종 화면은 `electricity/index.html`에 명시한 순서로 모형을 불러옵니다. `layout-*` 파일이 이전 그림을 대체합니다. 기존 기본 모형의 시험만 통과했다고 현재 화면을 검증한 것으로 보지 않습니다. 현재 등록 파일·조작 목록은 [주제별 구현 목록](topic-coverage.md)에 있습니다.

## 재현 가능한 검사

저장소 루트에서 `node tests/run.cjs`를 실행합니다. Node.js 외의 외부 패키지 없이 수치·상태·DOM 계약 검사를 실행할 수 있습니다. 이미지 렌더링은 별도 검사입니다.

- 83개 ID의 등록, 기본값·경계값·여러 시각, 유효한 출력, 조작의 관련 출력 변화.
- 직렬 KVL, 병렬 KCL, 전원 차단, 브리지 평형, 계단 스위치 네 조합.
- 전지 높이와 각 저항의 전압 강하, 병렬 가지의 같은 높이, 부품을 옮겨도 유지되는 연결.
- 여러 전압원과 자유 단자 배선의 절점 해석, 개방·단락·충돌·부동 회로, 이상적 고리의 미정 전류, 소비 전력 보존.
- 전하 보존, 유전체의 면적·간격·삽입, 검전기의 접지 순서, 전기력선의 방향과 순전하가 음수인 경우의 외부 유입.
- 자기장과 전류의 방향, 유도 기전력 부호, 발전기·변압기의 관계, 자기 이력의 상태 유지.
- RC/RL 시간 상수, LC 에너지, 정류 평균/RMS, 전류·전압 파형과 입자 이동의 위상.
- 그림 위 직접 조작의 좌표 변환, 취소·초기화·키보드 동작, 조건과 실제 상태 기록.
- 83개 주제의 화면 구성, 검색·메뉴·기록·CSV·인쇄 호출에 대한 DOM 계약 검사.

## 확인 수준을 구분합니다

원본의 실제 화면·조작을 확인한 사례와 공식 정지 그림 또는 설명으로만 확인한 사례를 구분합니다. 원본의 일부 WebGL 화면은 사용한 브라우저에서 오류가 나므로, 그 항목의 정확한 카메라 조작과 동작 일치를 인증하지 않습니다. 정지 그림을 확인했다는 사실은 새 구현이 정지 그림뿐이라는 뜻은 아닙니다. 새 구현의 움직임과 계산은 별도로 검사합니다.

실제 브라우저에서 확인한 조작과 수치 모형·DOM 모의 검사는 분야별 기록에 따로 적습니다. 모든 경로가 열린다는 검사는 모든 제스처를 실제 기기에서 확인했다는 뜻이 아닙니다. 실제 휴대폰·태블릿 터치, 마이크 하드웨어, 파일 다운로드·인쇄 대화상자는 별도 검증 대상입니다.

## 교육 모형의 경계

- 자유 회로 공방은 최대40개 추가 부품의 선형 DC 또는 저항성 AC 실효값 등가 해석입니다. 모터 기동·역률·비선형 전원·SPICE 전체 기능은 제공하지 않습니다. 서로 떨어진 회로 사이 전압과 이상 도선 고리의 일부 전류는 미정으로 표시합니다.
- 가전은 정격 전력으로 환산한 일정 저항입니다. 가정용 전원에 그림의 배선을 따라 연결하면 안 됩니다.
- micro:bit 항목은 가상 측정입니다. 실제 장치와 연결하거나 Bluetooth 측정을 했다고 표시하지 않습니다.
- 입자 수·속도·자화·분극·오로라·반도체의 공간 그림은 학습용 근사입니다. 길이와 시간 축척, 계산식과 근사의 조건은 각 수업 안내에 적습니다.
- 원본의 모든 자산, 정확한 제스처와3D 카메라 동작을 복제했다고 주장하지 않습니다. 관찰하지 못한 부분을 관찰 완료로 표시하지 않습니다.
