# RAON SCIENCE LAB — 전기·전자 과학·기술 검증 기록

작성 기준: 2026-11-05. 이 문서는 **실험 개수**와 **원본 참고 목록**을 혼동하지 않기 위해 작성되었습니다.

## 구현 범위

- `labs/electricity-studio.html`: 자체 작성된 **52개의 과학 모형**. 각 모델은 독립적인 조작 변수, 시각화, 계산 결과, 탐구 질문 및 이상화 가정을 제공합니다.
- `labs/circuit-builder.html`: 별도의 전구·전지 직렬·병렬 조립 실험.
- `electricity/catalog.json`: 과학 참고 사이트에서 분석한 83개 주제의 제목과 링크를 정리한 목록. 83개가 전부 원본과 동일한 인터랙션으로 구현되었다는 뜻이 **아닙니다**.
- `electricity/index.html`: 83개 참조 주제에 대해 관련된 자체 실험으로 이동하는 학습 안내.
- 다른 저작물의 프로그램·CSS·HTML·그림을 복사하거나 원본을 iframe으로 삽입하지 않습니다.

## 이론 기반

- 정전기: 점전하 쿨롱 법칙, 전하량 보존, 전위, 전기장 중첩.
- 회로: 옴의 법칙, 직·병렬, 전압 분배, 전력과 줄열, RC 충·방전, RL 응답, LC 진동, RLC 공진, 직렬 LC 및 부하 포함 필터.
- 자기와 전자기: 직선도선 및 원형도선 자기장, 솔레노이드 근사, 로렌츠 힘, 전동기 토크, 패러데이 유도 법칙, 교류 발전기와 이상적 변압기.
- 반도체와 신호: 이상화된 다이오드 Shockley 모형, BJT 전류 제어 모형, 디지털 논리, 반가산기, LED 전류제한, AM/FM 변조, 전자기파 관계식.
- 전기·자기 응용: 접촉식·정전식 센서, 자기권 개념도, 강자성체 자화의 정성 모델, 에너지 띠의 단순화 모형.

## 수행한 검증

1. 스튜디오 자바스크립트 문법 검사 통과.
2. 공개 GitHub Pages에서 52개 탭을 실제 눌러 각 모델의 측정 결과가 나타나는지 검사.
3. 각 모형의 최소·최대·기본 슬라이더 조합 총 156회에 대한 계산/렌더링 기본 검사. 예외 및 NaN, Infinity 출력 없음.
4. 정전기: ±2μC 두 전하, 거리 30cm에서 약 0.3994N. 거리 60cm에서는 약 0.0999N (거리 제곱 반비례).
5. 직선 도선: 5A, 8cm에서 약 12.5μT.
6. RC: 5kΩ, 200μF에서 시간상수 1초.
7. 유도: 80회 감은 코일, 30cm², 100mT, 1Hz에서 최대 약 0.1508V.
8. 브라우저에서 목록 주제 → 연계 실험 → 계산 화면 이동 확인.

## 과학적 적용 범위 및 주의

- 수업용 `이상화 모형`은 실제 실험기구·부품의 정격 예측용이 아닙니다.
- 일부 그림은 모형의 원리를 설명하는 정성적 그림입니다. 특히 검전기 각도, 자화의 도메인 배열, 자기권 크기, 도체 끝 전하 집중, 터치스크린 구조, 태양풍·오로라는 실측된 수치나 정밀 수치해석 결과가 아닙니다.
- 필라멘트 온도 의존 저항, 다이오드 항복, 코일 철심 포화, 실제 AC 전력망의 역률과 손실, DC–DC 스위칭 손실, 변압기 동손·철손, 계측기 오차를 생략했습니다.
- 전기 실습 시에는 반드시 저전압·전류제한 전원을 사용하고, 220V 배선이나 전원 단락 실험을 따라 해서는 안 됩니다.
- 52개 모형을 활용한 83개 학습 주제 링크는 **같은 개념을 공유하는 경우 재사용**합니다. 83개 원본 프로그램의 기능이 모두 독립적으로 재현되었다고 표시하지 않습니다.
